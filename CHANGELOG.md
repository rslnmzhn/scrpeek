# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-05-09

### Added

- `scrcpy-tui` standalone terminal UI binary.
- Device panel for selecting connected Android devices.
- Options form for configuring scrcpy launches interactively.
- Named launch profiles for saving and loading TUI launch settings.

scrcpy upstream: https://github.com/Genymobile/scrcpy
